# OguzzTok — Game Design Portfolio

Statik portfolyo sitesi: [Astro](https://astro.build) + Tailwind CSS, GitHub Pages'te yayınlanır.
İngilizce ve Türkçe; tüm içerik repo'daki dosyalardan gelir.

## Çalıştırma

Gerekli: Node.js 22.12 veya üzeri (bkz. `.nvmrc`).

```bash
npm install
npm run dev
```

Site http://localhost:4321 adresinde açılır.

| Komut | Ne yapar |
|---|---|
| `npm run dev` | Geliştirme sunucusu |
| `npm run check` | Tip kontrolü |
| `npm run build` | `dist/` klasörüne derler |
| `npm run preview` | Derlenmiş siteyi yerelde yayınlar |

İçerik ekleme rehberi: [CLAUDE.md](CLAUDE.md).

GitHub Pages kurulum adımları Faz 6'da eklenecek.
